# Consortium demo materials

Presentation and walkthrough materials for the CT entrepreneurship
consortium's federated-model demo. See `docs/federated-demo-plan.md` for the
run-of-show and `docs/live-demo-script.md` for the live terminal demo.

| File | What it is |
|---|---|
| `federated-demo-deck.html` | "The Federated Compact" — 15-slide deck (arrow keys or on-screen buttons; "View as document" stacks all slides). Self-contained single file — open it in any browser, or serve it anywhere. |
| `api-in-plain-english.html` | "The API in Plain English" — 8-slide short deck for a **non-technical decision maker at an organization not yet in the talks**. Same navigation as the main deck. Slide 4 is a replayable terminal that types out one real exchange line by line, with a plain-English gloss beside each line — the point being that the network is machines talking, not another screen to log into. Ends with the copy-paste sandbox commands to hand to their tech person. |
| `compact-in-practice.html` | "The Compact in Practice" — interactive walkthrough: agreement tiers, why-join, data model, taxonomy, field standard, real MakeHaven screenshots, and six step-through scenarios showing what updates locally vs. centrally. |

All three files are fully self-contained (styles, scripts, and screenshots
inlined), so they can be shared as attachments, opened from disk, or hosted
from any static host. The canonical shared copies are published as Claude
artifacts; this directory is the versioned source of record.

To try the API itself, see `docs/partner-api/TRY_IT.md`.

The embedded MakeHaven screenshots were captured 2026-08-27 from a real
push (MakeHaven's `entrepreneur_nexus_bridge` Drupal module → a test Nexus
node) and contain no member personal data.
